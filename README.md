# CARDFORGE

**카드를 조합하고, 나만의 덱을 만들어 가는 로그라이크 덱빌더**

*A roguelike deck-builder about combining cards and shaping your deck.*

CARDFORGE는 Unity 6로 개발 중인 턴제 카드 게임입니다.
전투에서 카드를 사용하고 조합하며, 보상과 상점에서 다음 전투를 위한 덱을 준비합니다.

## 핵심 플레이

### 카드 조합
같은 티어의 카드 두 장을 조합해 상위 티어 카드를 만듭니다.
지금 필요한 효과를 만들지, 기존 카드를 남겨 둘지 선택합니다.

### 전투와 덱 성장
적의 다음 행동을 보고 공격과 방어를 결정합니다.
전투 중 만든 조합 카드는 바로 영구 덱에 들어가지 않으며, 전투 후 각인을 통해 해당 런의 덱에 남길 수 있습니다.

### 보상과 선택
전투 보상, 상점과 경로 선택을 통해 덱을 다듬습니다.
카드 한 장의 효과뿐 아니라 함께 사용하는 조합을 생각하며 진행합니다.

## 개발 현황

**현재 개발 중입니다.**

카드 시스템, 적의 행동, UI, 이미지와 사운드를 구현하고 실제 플레이 흐름을 검증하고 있습니다.
개발 과정에서 기능과 구성은 달라질 수 있습니다.

- **엔진** — Unity 6
- **장르** — 로그라이크 덱빌더 / 턴제 카드 게임
- **지원 계획** — 영어 현지화, 모바일 출시

영어 지원과 모바일 버전은 계획 단계이며, 출시일은 아직 공개하지 않았습니다.

## About this repository

이 저장소는 CARDFORGE의 공개 소개를 위한 공간입니다.
현재 게임 소스 코드나 실행 파일은 포함되어 있지 않습니다.

CARDFORGE is currently in development. Combine cards, read enemy intentions, and shape your deck through combat rewards and choices. English localization and a mobile release are planned.

This repository presents the project; it does not currently contain the game source code or a playable build.
